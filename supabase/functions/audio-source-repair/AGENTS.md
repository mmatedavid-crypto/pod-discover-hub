# Audio source repair rules

- Automatic audio source verification and repair runs only through `audio-source-repair` (policy in `_shared/audio-source-repair.ts`, zero paid AI, zero server-side audio proxying) fed by `trg_player_events_enqueue_audio_repair` on `player_events` (`playback_error`) and hourly cron `podiverzum-audio-source-repair-hourly` (only invoking HTTP when due rows exist); writes go solely through `apply_audio_source_repair_v1` (CAS + `audio_source_repair_audit` + `revert_audio_source_repair_v1`), `trg_protect_repaired_audio_url` stops future RSS re-imports from reverting repaired enclosures, inconclusive probes or recent listener progress never disable working audio, and proven-dead episodes without an official audio file switch to `external_only` via verified episode-level links (`playerAudio.ts` / `playerFallback.ts` / `episode_cards_sync`), because broken migrated enclosures must be fixed or routed to real episode alternatives without breaking working streams.
