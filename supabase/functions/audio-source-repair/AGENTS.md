# Audio source repair rules

- Automatic audio source verification and repair runs only through `audio-source-repair` (policy in `_shared/audio-source-repair.ts`, zero paid AI, zero server-side audio proxying) covering all public HU shows (`language_decision = 'accept_hungarian'` and `rss_status <> 'inactive'`), fed by `trg_player_events_enqueue_audio_repair` (`priority=100`), optional targeted low-priority maintenance enqueues (`priority=40`, `error_event_count=0`, `requires_rss_match=true`), and rare due re-checks of `broken_no_alternative` (`20`) / `external_only` (`10`) via `claim_audio_source_repair_queue_v2` and hourly cron `podiverzum-audio-source-repair-hourly`; writes go solely through `apply_audio_source_repair_v1` (active-lease + CAS + `audio_source_repair_audit` + `revert_audio_source_repair_v1`), `trg_protect_repaired_audio_url` blocks RSS re-imports from reverting repaired enclosures, recovered sources automatically return to internal playback via `episode_cards_sync`, and inconclusive probes or recent listener progress never disable working audio, because broken enclosures must recover safely without stale workers, fake error counts, or global breakage.
