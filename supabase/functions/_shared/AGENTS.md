# Shared public catalogue rules
- Person hub copy uses `person-page-copy.ts` on the same first 40 public RPC rows in React and prerender; only verified links supply roles/topics/show context, because metadata and the visible introduction must agree without extra reads or generated biographies.
- Removed RSS items use `episode_ingest_exclusions` and `episode-ingest-exclusion.ts` before ingestion side effects, with the database trigger as the final guard, because a feed or another importer must never restore an excluded item.
- Duplicate show consolidation uses reversible `podcast_canonical_mappings` / `episode_canonical_mappings` (no hard deletes, alias ingestion suppressed in `fetch-one.ts`, conservative trailing-whitespace normalization in `rss-url-normalize.ts`); annual archives share `podcast-annual-archive.ts` (`get_podcast_year_archive_page_v1`, 100/page, strict 404 out-of-range); the 10-show active title/latest-episode trial shares `podcast-active-trial.ts` (explicit allowlist, no global switch), because React, prerender, sitemap and edge redirects must stay consistent and reversible.
