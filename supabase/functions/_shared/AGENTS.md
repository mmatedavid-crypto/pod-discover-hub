# Shared public catalogue rules
- Person hub copy uses `person-page-copy.ts` on the same first 40 public RPC rows in React and prerender; only verified links supply roles/topics/show context, because metadata and the visible introduction must agree without extra reads or generated biographies.
- Removed RSS items use `episode_ingest_exclusions` and `episode-ingest-exclusion.ts` before ingestion side effects, with the database trigger as the final guard, because a feed or another importer must never restore an excluded item.
- Duplicate show consolidation uses reversible `podcast_canonical_mappings` / `episode_canonical_mappings` / `episode_podcast_reassignments` (`apply_podcast_lossless_merge_v1`, no hard deletes, alias ingestion suppressed and existing slugs preserved on reconciliation in `fetch-one.ts`, conservative trailing-whitespace normalization in `rss-url-normalize.ts`); annual archives share `podcast-annual-archive.ts` (`get_podcast_year_archive_page_v1`, 100/page, strict 404 out-of-range, `published_at <= now()` and `is_prefetch_placeholder IS NOT TRUE`); the 10-show active title/latest-episode trial + 7 fixed controls share `podcast-active-trial.ts` (explicit allowlist, no global switch, scoped additive native `play_playing` event in `SmartPlayerProvider`), because React, prerender, sitemap, telemetry and edge redirects must stay consistent and reversible.
